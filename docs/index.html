WorkBar.

在 MacBook Pro 的 Touch Bar 上常驻显示 WorkBuddy 的任务状态 —— 不用切回窗口，就知道它在做什么、做到哪一步、有没有需要你确认。

macOS 原生 · Swift + AppKit 零第三方依赖 不弹窗 · 不抢焦点

状态显示

Touch Bar 随 WorkBuddy 的状态自动切换，宽度不足时按优先级保留最重要的信息。

交互

操作效果
点摘要区激活并跳转到 WorkBuddy
点任务条切换紧凑 / 详情视图
横滑任务条切换聚焦任务（多任务时标题带 (1/2) 序号）
在 WorkBuddy 里切换会话Touch Bar 标题与详情自动跟随
点弹层 / 权限选项等价于在 WorkBuddy 界面里按那个按钮
点系统栏 logo用「×」关掉后，点它可重新打开

快速开始

需要带 Touch Bar 的 MacBook Pro，macOS 14 及以上。

git clone https://github.com/Miragic/WorkBar.git
cd WorkBar
./Scripts/build-direct.sh
open build/WorkBar.app
设置面板
菜单栏图标 → 设置，可以按自己的习惯开关显示项、调整顺序，右侧有实时预览；还可切换「空闲统计口径」为今日累计或本轮消耗。

设计原则

  • 无感呈现 —— 所有信息都从本地数据库读取，不弹窗、不抢焦点、不为了读一个数值打断你的操作。
  • 诚实降级 —— 私有 API 缺失时显示不出就显示不出，不崩、不假装。
  • 宽度就是预算 —— Touch Bar 可用宽度约 290pt，任何新增信息都要先算清吃多少 pt。

已知限制

  • 常驻依赖私有 API —— presentSystemModalTouchBar，macOS 大版本升级后可能失效。
  • 仅适配 WorkBuddy —— 状态归约与展示层已分层，但数据源目前只接了它。
  • 「已完成」态需要未读标记 —— WorkBuddy 当前不写该字段，实际完成后会直接回到空闲。
  • 语音输入暂搁置 —— 功能已实现，但 Touch Bar 上长按手势与点击会打架。
